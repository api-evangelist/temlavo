# Temlavo — Invoice Extraction API

> Temlavo turns invoice PDFs and images into versioned accounting JSON using AI extraction, practical consistency checks, duplicate signals, and explicit review outcomes.

Built for developers, automation consultants, and agencies creating invoice-processing workflows for small and medium-sized businesses. Integrate through the server-side TypeScript SDK and CLI, HTTP API, or n8n. The initial commercial focus is US/English invoices.

Temlavo provides invoice extraction and structured-data checks. It is not a complete bookkeeping application or payment-approval system. Customers retain control of downstream accounting, review, and payment decisions.

Processing is asynchronous: create a document, upload its source, confirm the upload, and poll the authenticated document resource for a terminal outcome:

- `completed`: no blocking declared check under the document's policy; warnings may remain.
- `needs_review`: usable structured data with blocking findings that require attention.
- `failed`: processing did not produce a usable result.

Checks assess extracted structured data. A `completed` outcome does not independently verify source accuracy, establish tax compliance, or authorize payment.

Required fields, line-item acceptance, and duplicate detection share one per-document review policy across integrations. Policy changes acceptance behavior, not extraction effort or accuracy.

API keys are server-side secrets. Never embed them in browser code. Use the returned signed upload method, URL, and all returned headers exactly. Never forward Temlavo API credentials to the upload origin, and do not automatically follow upload redirects.
